# Attention

A reading app that keeps you on the page: select any words in a hard paper and tap ⌘ twice for a short explanation linked back to the text. Follow-ups, read-aloud with a word underline, an outline and minimap, study notes, and a quiz that starts with what you asked about.

**Use it:** https://honnofenix.github.io/attention-app/

- Open a PDF, EPUB or Markdown file, or start with one of the samples below.
- Live answers: download Qwen3 4B once (about 2.3 GB, runs privately in your browser with WebGPU, then works offline), or add your own OpenAI or Anthropic API key. Keys and documents stay in your browser.
- Best in Chrome or Edge on a recent Mac or PC.

This repository only holds the built app (`index.html`) and its sample documents (`samples/`), published automatically.
